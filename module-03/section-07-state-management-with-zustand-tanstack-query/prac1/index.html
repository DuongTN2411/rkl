Nhấn "Toggle Sidebar" hoặc đổi "role" nhiều lần. Header BAD sẽ tăng số lần render, Header GOOD (dùng selector) thì không đổi vì nó chỉ quan tâm tới "theme".

Phân tích

Trong đoạn code lỗi, useAppStore() được gọi không có selector, nghĩa là component đăng ký lắng nghe TOÀN BỘ state. Bất kỳ field nào trong store đổi (kể cả sidebarOpen, userRole không liên quan tới Header) đều khiến Zustand phát tín hiệu update và Header render lại, phá vỡ triết lý "chỉ render khi phần state mình dùng thay đổi" của Zustand.

Cách sửa: dùng selector useAppStore(state => state.theme) để chỉ subscribe đúng phần cần thiết, hoặc dùng useAppStore(useShallow(state => ({...}))) khi cần nhiều field nhưng so sánh nông để tránh render thừa.
