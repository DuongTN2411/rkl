Bài 4 - Luồng gọi API phụ thuộc (Dependent Queries)

Chọn một đơn hàng. Query 1 lấy thông tin đơn hàng. Query 2 (lịch sử giao hàng) chỉ được gọi (enabled) khi Query 1 đã trả về trackingId khác null.

Query 1: Thông tin đơn hàng

-

Query 2: Lịch sử giao hàng (phụ thuộc trackingId)

Chưa đủ điều kiện để gọi (trackingId = null)

Sơ đồ luồng điều kiện

useQuery(orderInfo) chạy ngay lập tức khi component mount. useQuery(shippingHistory) có option enabled: !!trackingId, nghĩa là hook này tồn tại nhưng KHÔNG tự fetch cho tới khi trackingId (lấy từ kết quả Query 1) khác null/undefined. Nếu đơn hàng chưa giao cho vận chuyển (trackingId = null), Query 2 sẽ giữ trạng thái "chưa chạy" vĩnh viễn, tránh gọi API với tham số rỗng gây lỗi 400 Bad Request.
