Bài 2 - Cập nhật giá Sản phẩm (mô phỏng TanStack Query)

Chọn sản phẩm, nhập giá mới rồi bấm "Cập nhật giá". Danh sách bên dưới sẽ tự làm mới (refetch) ngay sau khi Mutation thành công, không cần F5.

Phân tích

Đoạn code lỗi chỉ gọi mutationFn rồi hiển thị toast, không hề báo cho query cache biết rằng dữ liệu "products" đã cũ. TanStack Query mặc định KHÔNG tự refetch một query đang cache trừ khi cache đó bị đánh dấu invalid (stale) hoặc window được focus lại.

Cách sửa: trong onSuccess của useMutation, gọi queryClient.invalidateQueries({queryKey: ['products']}) để đánh dấu cache 'products' là stale, buộc TanStack Query tự động refetch và UI cập nhật giá mới ngay lập tức.
