Bài 7 - Cập nhật dữ liệu ngay lập tức (Optimistic Updates)

Bấm nút Thích. Server phản hồi chậm (~2 giây) nhưng UI đổi màu xanh ngay lập tức (Optimistic). Bấm nút "Giả lập lỗi mạng" để xem hành vi Rollback khi API thất bại.

Bài viết mẫu: "Học RTK Query thật thú vị!"

Phân tích (2 hướng)

Hướng 1 - Pessimistic: bật cờ isLoading, khóa nút Like lại, đợi API trả về (2 giây) rồi mới đổi màu xanh. An toàn tuyệt đối nhưng UX chậm, người dùng phải chờ.

Hướng 2 - Optimistic: đổi màu xanh + tăng số Like ngay khi bấm (trước khi có response), dùng onQueryStarted của RTK Query. Nếu API trả lỗi, dispatch patch.undo() để Rollback về trạng thái ban đầu.

Lựa chọn: Hướng 2 - Optimistic Update, vì ưu tiên trải nghiệm UX mượt cho hành động Like, chấp nhận độ phức tạp code tăng nhẹ để đổi lấy cảm giác tức thì.
