Bài 6 - Phân tích và Tối ưu Autocomplete Search (Chống Spam API)

Gõ nhanh vào ô tìm kiếm (ví dụ: "Macbook"). Bộ đếm "Số request đã gửi" cho thấy giải pháp Debounce giảm số lần gọi API xuống chỉ còn 1 lần sau khi người dùng ngừng gõ 400ms.

Số ký tự đã gõ: 0  |  Số request đã gửi (debounce): 0

    1) Phân tích & Đề xuất (2 giải pháp)

    Giải pháp 1 - Debounce (setTimeout thuần trong Component): mỗi lần người dùng gõ, hủy timer cũ và đặt timer mới (vd 400ms). Chỉ khi hết 400ms mà không có ký tự mới, mới thực sự gọi API.

    Giải pháp 2 - Hủy request cũ / skip tham số (Redux Thunk / RTK Query): cấu hình RTK Query tự động abort request trước đó khi có request mới với query key khác, kết hợp tham số "skip" khi input rỗng.

    2) So sánh & Lựa chọn
