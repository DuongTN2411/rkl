Bài 9 - Hệ thống Mini Notification (Bắt lỗi Global)

Bấm các nút API dưới đây. Một Middleware trung tâm sẽ "nghe" mọi action bị lỗi (kết thúc bằng .rejected) và tự động hiện Toast báo lỗi, không cần bất kỳ Component nào tự viết code hiển thị lỗi.

Thiết kế kiến trúc

Một custom middleware được gắn vào configureStore/dispatch pipeline. Middleware này chặn (intercept) MỌI action đi qua Store trước khi tới reducer; nếu action.type kết thúc bằng ".rejected" (quy ước của RTK Query/Redux Thunk khi 1 request thất bại), middleware sẽ tự lấy action.error.message rồi đẩy một thông báo Toast lên góc màn hình - hoàn toàn tách biệt khỏi logic của Component gọi API.
