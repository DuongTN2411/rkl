Bài 10 - Cỗ máy Quản lý luồng Checkout (Mini E-commerce)

Sơ đồ luồng dữ liệu (Data flow)

(1) Danh sách sản phẩm được lấy từ Server qua RTK Query (mô phỏng). (2) Khi bấm "Thêm vào giỏ", dữ liệu được ghi vào cartSlice (Redux, Client State cục bộ). (3) Form địa chỉ giao hàng cũng là một shippingSlice (Client State) cục bộ, cập nhật theo mỗi lần gõ. (4) Khi bấm "Thanh toán", Component gộp dữ liệu từ cartSlice + shippingSlice thành 1 payload, gọi RTK Query Mutation createOrder(payload) gửi lên Server. (5) Nếu Server trả về thành công, dispatch action clearCart() để dọn sạch giỏ hàng nội bộ; nếu mạng lỗi/chậm, hiển thị thông báo lỗi và giữ nguyên giỏ hàng, không làm crash ứng dụng.
