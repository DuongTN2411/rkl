Bài 5 - Đồng bộ Client State & Server State (Filter/Search)

Nhập từ khóa tìm kiếm sản phẩm. Từ khóa được lưu vào searchSlice (Client State), sau đó hook đọc searchSlice này để gọi API lấy dữ liệu (Server State). Nếu nhập toàn khoảng trắng, hệ thống sẽ KHÔNG gọi API.

searchSlice hiện tại: ""

    Báo cáo phân tích - Giải pháp nối dữ liệu

    1) Tạo một searchSlice (Client State) chỉ giữ 1 field "keyword", có action setKeyword. 2) Component input gọi dispatch(setKeyword(value)) mỗi khi người dùng gõ. 3) Hook của RTK Query (useGetProductsQuery) đọc keyword này qua useSelector, rồi dùng chính giá trị đó làm query param truyền vào endpoint getProducts(keyword). 4) Trước khi gọi API, hook luôn trim() keyword; nếu chuỗi rỗng sau khi trim, truyền skip: true (hoặc bỏ qua fetch) để không tốn tài nguyên gọi API vô ích.
