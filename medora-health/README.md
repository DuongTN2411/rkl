# Medora Health

Patient portal concept cho hệ thống bệnh viện đa chuyên khoa Medora.

## Chạy project

Mở `index.html` trực tiếp bằng trình duyệt, hoặc chạy server tĩnh tại thư mục này:

```bash
python3 -m http.server 4173
```

Sau đó truy cập `http://localhost:4173`.

## Có sẵn

- Dashboard chăm sóc sức khỏe cá nhân responsive.
- Sidebar điều hướng và mobile menu.
- Tìm kiếm bác sĩ, chuyên khoa, hồ sơ và cơ sở.
- Modal đặt lịch khám với lựa chọn chuyên khoa, bác sĩ, ngày và ghi chú.
- Modal hồ sơ bệnh nhân và panel thông báo.
- Lịch hẹn, health score, biểu đồ vận động, vitals, đội ngũ chăm sóc và bản đồ cơ sở.
- Toast feedback cho các thao tác chính.
- Không cần dependency hoặc bước build.
